# Hand-entered data

These figures are published only in reports, not as downloadable tables, so they are typed in here.
Every row has a `source` link. Update once a year when a new report comes out, then push.

| File | Source | Next update |
|---|---|---|
| `shelter_use.csv` | National Shelter Study (Housing, Infrastructure and Communities Canada), 2023 update | When the 2024 update is published |
| `food_banks.csv` | Food Banks Canada, HungerCount (March of each year) | Each October/November |

Notes
- `food_banks.csv`: 2025 Canada total is the sum of the provincial figures (the report rounds it to 2.166 million).
  No HungerCount was run in 2020. Provincial figures for 2022 and 2023 were not collected here yet.
- Columns: `date` (YYYY-MM-DD), any category columns, `value`, `unit`, `source`. Add rows; keep the same columns.
